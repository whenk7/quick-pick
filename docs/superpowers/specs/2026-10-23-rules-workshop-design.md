  规则页卡片 `</>`（JSON 预览）疑同根因，本轮补点击测试坐实。

## 规则页

```
🧩 匹配规则            N 条规则，2 个预置
[📥 导入] [🤖 AI 生成] [📤 导出]     ← 横排三按钮（紧凑，熟练工入口）
预置规则
  卡片（点编辑 / </> JSON 预览 / 🗑 删除）
自定义规则
  …
[+ 新增匹配规则]
```

- 导入：弹窗（限高 0.7 屏、内容滚动）= 大输入框 + [粘贴] + [选文件] → 智能识别单对象/数组、
  剥 markdown 围栏 → 逐条预览 → 确认入库（沿用现有冲突裁决流）
- 导出：弹窗二选一 [复制到剪贴板] [存为文件]（SAF CreateDocument），不再走系统分享面板
- 设置页删除「AI 生成规则」「导出全部规则」「导入规则」三个入口

## AI 生成规则页（复用 ai_prompt 路由重写）

三段式单页（限高卡片 + 内部滚动）：

1. **短信样本**：收件箱近 90 天自动挑选——含「取件码/取货码/包裹/驿站/柜」关键词的算快递样本，
   有【】签名但不含的算通知样本（反面教材，防生成的规则误报）。目标 15 快递 + 5 通知。
   只展示正文（不带发送方/时间），逐条可 [×] 移除；**「补齐」按钮手动补**（不自动塞，
   从候选池取下一条，点到没有候选为止）
2. **提示词**：自动生成（含确认的样本全文），[一键复制]
3. **粘贴结果**：大输入框 + [检查并导入] → 同导入弹窗的解析/预览/入库

提示词重写要点（进 AiPromptViewModel，同步 .res/ai-prompt-template.md）：
- 完整新 schema：name + senderPattern + fields{trackingNumber,pickupCode,address,phone,brand}，
  每字段 prefix/suffix
- 告知引擎语义：indexOf 首次出现、suffix 留空取到文末、suffix 配了没命中判 null（E1）、
  brand 用【】签名、senderPattern 是发件方子串过滤可留空
- 通知样本标为「不要为它们生成规则」
- 输出严格 JSON 数组，无任何解释文字
