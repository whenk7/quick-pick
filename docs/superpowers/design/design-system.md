# 取件宝 — 视觉设计系统

## 设计方向：治愈系极简

**核心定位**：不是冰冷的快递工具，而是帮你轻松搞定快递琐事的贴心小助手。

**核心情绪**：清爽、有序、安心、无负担。

**设计原则**：
- 颜色克制，低饱和，不制造视觉焦虑
- 文字温和，不用"错误""失败""必须"等负面词汇
- 动效柔和不突兀，禁弹跳/震动/旋转
- 大圆角 + 轻阴影 + 充足留白

## 一、色彩系统

| Token | 色值 | 用途 |
|-------|------|------|
| 主色 | `#6AB37B` (豆绿) | 按钮、取件码、选中态、强调元素 |
| 主色浅 | `#A8D5B0` | 主色的低饱和版本，背景点缀 |
| 背景色 | `#F9F9F6` (暖米白) | 页面底色 |
| 卡片色 | `#FFFFFF` | 卡片、输入框表面 |
| 卡片-已取件 | `#F5F5F5` | 已取件卡片背景，置灰感 |
| 文字主色 | `#424242` | 标题、正文 |
| 文字次色 | `#757575` | 辅助信息、标签 |
| 文字辅色 | `#9E9E9E` | 占位符、禁用态 |
| 辅助橙 | `#FFB76B` | 未取件/待处理标识 |
| 辅助灰 | `#BDBDBD` | 已取件/已完成标识 |
| 危险色 | `#EF5350` | 仅用于删除操作，尽量少用 |
| 分割线 | `#EEEEEE` | 分隔、细线边框 |

**原则**：绝对不用高饱和红/黄标记"未取件"，避免给用户制造"有事没做完"的焦虑感。

## 三、字体

| 用途 | 大小 | 字重 | 说明 |
|------|------|------|------|
| 取件码 | 28sp | Bold | 页面最重要信息，豆绿色 |
| 页面标题 | 28sp | Bold | #424242 |
| 分组标题 | 18sp | Medium | #424242 |
| 公司名 | 16sp | Medium | #424242 |
| 正文 | 15sp | Regular | #424242 |
| 辅助字段 | 14sp | Regular | #757575 |
| 小字/标签 | 12sp | Regular | #9E9E9E |
| 时间戳 | 12sp | Regular | #9E9E9E |

**字体推荐**：圆润无衬线体，如阿里巴巴普惠体 Rounded。取件码使用等宽数字变体（tabular numbers）。

**文字颜色一律不用纯黑 `#000000`**，全部使用深灰系列，避免对比过强造成压迫感。

## 五、阴影

- 卡片默认：elevation 2dp，极轻
- 卡片展开/选中：elevation 4dp
- 弹窗：elevation 8dp
- Material 3 默认 elevation 需整体降低，避免阴影过重

## 七、动效

| 场景 | 时长 | 曲线 |
|------|------|------|
| 页面切换 | 250ms | ease-out |
| 卡片展开/收起 | 200ms | ease-out |
| 标记已取件过渡 | 300ms | ease-out |
| 按钮点击反馈 | 150ms | scale 95% + 变暗 10% |

**禁用**：弹跳、震动、旋转、弹簧等强烈动效。

---

## 八、文案规范

| 避免 | 改用 |
|------|------|
| 匹配失败 | 暂时没有匹配到 |
| 必须填写 | 选填，填写后更准确 |
| 删除后无法恢复 | 删除后将无法恢复，确定要删除吗？ |
| 错误 | 出了点问题 |

---

## 九、图标方案

- UI 图标使用 **emoji**（底部导航：📦 快递 / 🧩 规则 / ⚙️ 设置），零版权风险、零资源文件
- 快递公司标识：不放 logo，用 8dp 品牌色圆点（色值见品牌色表）
- 品牌 IP「小取」：v1 用 emoji 📦 占位，后续有美术资源再换
- ~~Iconfont SVG 方案~~（已废弃：版权筛选成本高，与极简定位不符）

## 十、品牌 IP

- **名称**：小取
- **造型**：圆润小包裹，顶部两个小耳朵，圆眼微笑
- **色彩**：豆绿色填充 + 白色面部
- **应用**：启动页、空状态、加载页、权限引导页、关于页
- **动效**：呼吸动画（加载时），不使用传统转圈
- **v1 实现**：以 emoji 📦 占位，后续有美术资源再换

---

## 十一、Material 3 适配

1. 关闭默认动态颜色（Dynamic Color），使用自定义色彩
2. 覆盖 Shape Theme，统一圆角
3. 自定义 Typography，使用圆润无衬线字体
4. 降低默认 Elevation 值
5. 关闭默认波纹（Ripple），用缩放+变暗替代
