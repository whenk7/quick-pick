# 取件宝 — 视觉设计系统

## 设计方向：取件卡 (Parcel Card)

灵感来自实体取件凭条和快递面单。温暖、有触感、精致。取件码是页面上最重要、最醒目的元素。

### 色彩系统

| Token | 色值 | 用途 |
|-------|------|------|
| 背景色 | `#FAF6F0` | 页面底色，暖奶油色 |
| 卡片色 | `#FFFFFF` | 卡片表面 |
| 卡片-已取件 | `#EDEAE4` | 已取件卡片底色，褪色感 |
| 主强调色 | `#C4693B` | 按钮、取件码、选中态 |
| 文字主色 | `#2C2218` | 正文，暖深褐 |
| 文字次色 | `#8C8278` | 辅助信息 |
| 分割线 | `#E8E4DD` | 分隔、边框 |
| 成功绿 | `#6B9E6F` | 已取件勾选 |
| 不完整橙 | `#E0A15E` | 不完整标注 |

### 快递公司色标

每个快递公司一个独特的"邮戳色"，用作卡片左侧色条和图标底色：

| 公司 | 色值 |
|------|------|
| 顺丰 | `#E85D3A` |
| 京东 | `#D4232E` |
| 极兔 | `#FF6B35` |
| 中通 | `#2979FF` |
| 圆通 | `#9C27B0` |
| 韵达 | `#F5A623` |
| 申通 | `#00ACC1` |
| 邮政EMS | `#43A047` |
| 自定义 | `#C4693B`（默认） |

### 字体

| 用途 | 大小 | 字重 |
|------|------|------|
| 取件码 | 28sp | Bold |
| 公司名 | 16sp | SemiBold |
| 地址 | 14sp | Regular |
| 单号 | 13sp | Regular |
| 日期分组标题 | 13sp | Medium |
| 底部导航标签 | 11sp | Medium |
| 正文 | 15sp | Regular |

取件码使用等宽数字变体（tabular numbers），确保不同数字宽度一致、视觉整齐。

### 圆角

| 元素 | 圆角 |
|------|------|
| 卡片 | 16dp |
| 按钮 | 24dp（胶囊形） |
| 色标/邮戳 | 8dp |
| 输入框 | 12dp |
| 分词块 | 8dp |
| 底部导航 | 0（直角） |

### 阴影

卡片阴影：`elevation 1dp`（极轻），颜色用暖褐而非纯黑。
- 展开态：`elevation 3dp`

### 间距

- 页面水平边距：16dp
- 卡片内边距：16dp
- 卡片间距：10dp
- 分组间距：24dp
- 字段间距：8dp
