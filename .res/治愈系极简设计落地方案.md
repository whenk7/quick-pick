# 取件宝(QuickPick) 治愈系极简设计落地方案
结合你之前的治愈系设计清单和取件宝的产品规格，我为你制定了一份**完全可落地、针对性极强**的设计执行方案。核心思路是：**用治愈系的设计语言，把"处理快递"这件琐事从"麻烦事"变成"轻松事"**，让用户打开App时感受到的是"清爽、有序、无压力"，而不是传统工具App的冰冷和功利。

## 一、核心设计定位调整
首先明确取件宝的设计灵魂：
- **不是**：一个高效但冰冷的快递信息提取工具
- **而是**：一个帮你**轻松搞定快递琐事**的贴心小助手
- **核心情绪**：清爽、有序、安心、无负担
- **设计口号**：让取快递，变成一件简单快乐的小事

## 二、色彩系统定制（完全适配快递场景）
基于你之前的色彩规范，为取件宝量身定制：

| 色彩类型 | 具体取值 | 设计说明 |
|---------|---------|---------|
| **主色调** | 主题系统接管（2026-10-22 起）：固定配色 = miuix 内置板；Monet 动态配色由壁纸/种子色生成 | 色彩身份不再固定，治愈感由圆角、留白、柔和动效与温和文案承载 |
| **背景色** | 暖调米白色<br>RGB: 249, 249, 246 | 比纯白更柔和，长时间看快递列表也不会视觉疲劳 |
| **辅助色1** | 浅橙色<br>RGB: 255, 183, 107<br>饱和度: 32% | 用于"未取件"状态的轻微强调，代表"待处理"，比红色更温和 |
| **辅助色2** | 浅灰色<br>RGB: 189, 189, 189 | 用于"已取件"状态，代表"已完成"，视觉上自然弱化 |
| **文字色** | 主文字: #424242<br>次要文字: #757575<br>辅助文字: #9E9E9E | 全部使用深灰系列，避免纯黑的压迫感 |
| **危险色** | 低饱和红色<br>RGB: 239, 83, 80<br>饱和度: 35% | 仅用于删除操作，且尽量少用 |

**避坑提醒**：绝对不要用高饱和的红色、黄色来标记"未取件"，会给用户带来"有事情没做完"的焦虑感。

## 三、核心页面设计规范
### 1. 快递列表页（主页面）
这是用户最常使用的页面，设计的核心是**"一眼找到取件码"**和**"一键标记已取件"**。

#### 快递卡片设计（最核心组件）
- **造型**：大圆角矩形，圆角半径16pt，轻微阴影(elevation=2dp)
- **未取件状态**：
  - 背景：米白色(#FFFFFF)
  - 取件码：**24pt 粗体 主色**，放在卡片最上方最醒目的位置
  - 快递公司名：16pt 中等字重 主文字色
  - 其他字段：14pt 常规字重 次要文字色
  - 右上角勾选按钮：空心圆 + 主色描边
- **已取件状态**：
  - 背景：浅灰色(#F5F5F5)
  - 所有文字：透明度50%
  - 取件码：添加删除线
  - 右上角勾选按钮：实心圆 + 主色填充 + 白色对勾
- **不完整状态**：
  - 卡片右上角添加一个**浅灰色**的"不完整"标签（不要用红色）
  - 下方添加一行小字："点击编辑完善信息"
- **交互**：
  - 点击卡片：平滑展开/收起详情，动画时长200ms
  - 点击勾选按钮：卡片在300ms内平滑过渡到已取件状态
  - 长按卡片：弹出复制菜单，选项用文字按钮

#### 按天分组设计
- 分组标题：18pt 中等字重 主文字色，左对齐
- 分组折叠/展开按钮：主色小箭头，点击时有轻微旋转动画
- 按天一键已取件按钮：文字按钮，主色文字，放在分组标题右侧
- 分组间距：上下各16pt，保证呼吸感

#### 顶部快捷操作栏
- 背景：透明，与列表背景融为一体
- 按钮：圆角矩形(12pt)，浅灰色背景，主色文字
- 按钮间距：16pt
- 避免使用任何图标，只用文字，保持界面干净

### 2. 匹配规则页
- 规则卡片：与快递卡片保持一致的大圆角设计(16pt)
- 预置规则：左上角添加一个**浅灰色**的"预置"标签
- 自定义规则：无标签
- 每条规则显示：公司名(16pt) + 匹配字段数(14pt 浅灰色)
- 操作按钮：文字按钮，主色文字，放在卡片右侧

### 3. 规则编辑器（核心功能页）
这是最复杂的页面，设计的核心是**"降低用户的学习成本"**。

- 短信输入框：大圆角矩形(16pt)，浅灰色背景，内边距16pt
- 分词块：
  - 造型：圆角矩形(8pt)，浅灰色背景
  - 选中状态：主色背景 + 白色文字
  - 点击反馈：轻微缩放(95%)
- 字段输入区：
  - 每个字段一行，左对齐
  - 字段名：14pt 中等字重 主文字色
  - 输入框：下划线样式，浅灰色下划线
  - 选中状态：主色下划线
- 实时预览区：
  - 背景：浅灰色(#F5F5F5)
  - 匹配成功：绿色高亮(主色，透明度30%)
  - 匹配异常：浅橙色高亮(透明度30%)
- 保存按钮：底部固定，大圆角(16pt)，主色填充，白色文字

### 4. 设置页
- 采用列表式设计，每个选项一行
- 选项高度：56pt，保证点击区域足够大
- 选项文字：16pt 主文字色
- 右侧箭头：浅灰色
- 分隔线：浅灰色(#EEEEEE)，1px
- 重点突出"本地存储声明"：
  - 单独一个卡片，大圆角(16pt)
  - 背景：主色，透明度10%
  - 文字：主色，中等字重
  - 图标：一个小盾牌图标，主色

### 5. 首次启动与权限引导页
这是建立用户信任的关键页面，一定要设计得非常友好。

- 背景：米白色
- 顶部：一个可爱的小包裹IP形象（见下文IP设计）
- 标题："欢迎使用取件宝"，28pt 粗体 主文字色
- 说明文字：
  > 我们需要读取您的短信，来自动提取快递取件信息。
  > 
  > ✅ 所有数据仅存储在您的设备本地
  > ✅ 不上传任何信息到服务器
  > ✅ 不收集任何隐私数据
- 授权按钮：大圆角(16pt)，主色填充，白色文字，文字内容"授权并开始使用"
- 绝对不要使用"必须授权"、"否则无法使用"这类命令式语言

## 四、通用组件与交互规范
完全遵循你之前的治愈系设计清单，针对取件宝做以下调整：

### 1. 按钮组件
- 主按钮：圆角16pt，高度48pt，主色填充，白色文字
- 次要按钮：圆角16pt，高度48pt，浅灰色背景，主色文字
- 文字按钮：无背景，主色文字，16pt
- 所有按钮点击反馈：轻微缩放(95%) + 变暗10%，动画时长150ms

### 2. 加载与空状态
- 加载页：使用小包裹IP的呼吸动画，代替传统的转圈加载
- 快递列表空状态：
  - 显示一个抱着包裹的小豆子IP
  - 文案："还没有快递哦，坐等收货～"
- 规则列表空状态：
  - 显示一个拿着笔记本的小豆子IP
  - 文案："还没有自定义规则，点击右上角添加"

### 3. 动效设计
- 所有页面切换：淡入淡出，时长250ms，ease-out曲线
- 卡片展开/收起：平滑高度变化，时长200ms
- 标记已取件：卡片背景和文字透明度平滑过渡，时长300ms
- 绝对不要使用任何弹跳、震动、旋转等强烈动效

### 4. 文案语气
- 全部使用温和、友好的语气
- 避免使用"错误"、"失败"、"必须"这类负面词汇
- 例如：
  - 把"匹配失败"改为"暂时没有匹配到"
  - 把"必须填写"改为"选填，填写后更准确"
  - 把"删除后无法恢复"改为"删除后将无法恢复，确定要删除吗？"

## 五、品牌IP设计（打造记忆点）
为取件宝设计一个简单可爱的IP形象，增加产品的温度：

- **IP名称**：小取
- **造型**：一个圆润的小包裹，顶部有两个小耳朵，脸上有两个圆圆的眼睛和一个微笑的嘴巴
- **色彩**：跟随当前主题主色填充，白色面部
- **应用场景**：
  - 启动页图标
  - 空状态和加载页
  - 权限引导页
  - 设置页的关于部分
- **设计原则**：保持极简，不要添加过多装饰，与整体风格统一

## 六、Material 3 适配注意事项
因为你使用Jetpack Compose + Material 3，需要注意以下几点：

1. **关闭Material 3的默认动态颜色**，使用我们自定义的色彩系统
2. **覆盖默认的形状主题**，将所有组件的圆角半径设置为我们规范的数值
3. **自定义Typography**，使用圆润无衬线字体（如阿里巴巴普惠体Rounded）
4. **降低默认的elevation值**，避免阴影过重，保持界面轻盈
5. **关闭默认的波纹效果**，改用我们自定义的缩放+变暗点击反馈

## 七、落地优先级建议
按照以下顺序进行开发，可以最快看到效果：

1. **第一步**：搭建基础色彩系统和字体系统
2. **第二步**：实现快递卡片和列表页
3. **第三步**：实现标记已取件和一键操作功能
4. **第四步**：实现规则列表和规则编辑器
5. **第五步**：添加空状态、加载页和IP形象
6. **第六步**：优化动效和交互细节

## 八、验收标准补充
在你原有的验收清单基础上，增加以下设计验收项：

1. 所有页面的色彩都符合我们的规范，没有出现高饱和颜色
2. 所有组件的圆角半径都≥12pt，没有尖锐边角
3. 文字与背景的对比度在4.5:1-7:1之间，保证可读性
4. 所有动效时长在200-300ms之间，柔和不突兀
5. 所有按钮的点击区域都≥48×48pt
6. 空状态和加载页都有友好的IP形象和文案
7. 权限引导页清晰说明了隐私政策，没有使用命令式语言

## 总结
按照这个方案落地，你的取件宝App将会在保持工具类App高效性的同时，拥有治愈系产品特有的"松弛感"和"温度"。用户打开App时，不会感受到"又有一堆快递要处理"的压力，而是会觉得"哇，这个App好清爽，处理快递原来这么简单"。
