## 二、取件宝App使用建议
### 1. 最佳使用方式
- **小面积点缀**：在快递卡片的快递公司名称前，用一个**8×8dp的小圆点**显示品牌色
- **文字颜色**：快递公司名称可以使用品牌色，但要降低饱和度（建议饱和度≤50%），避免与整体治愈系风格冲突
- **选中状态**：当用户选中某张快递卡片时，可以用品牌色作为边框色

### 2. 避坑指南
- ❌ 不要用品牌色作为卡片背景色，会显得非常杂乱
- ❌ 不要用高饱和的品牌色作为大面积文字颜色，会造成视觉疲劳
- ❌ 不要同时在一张卡片上使用多种品牌色

// 快递卡片中的品牌色小圆点
@Composable
fun BrandColorDot(color: Color) {
    Box(
        modifier = Modifier
            .size(8.dp)
            .clip(CircleShape)
            .background(color)
    )
}
