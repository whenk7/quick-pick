# 取件宝 — 边界情况处理

## 一、权限相关

| 场景 | 处理 |
|------|------|
| 用户拒绝短信权限 | 快递列表页显示空状态："需要短信权限才能提取快递信息"，下方按钮"前往授权"→ 跳系统设置 |
| 权限被永久拒绝（不再询问） | 同上，按钮跳转应用设置页，提示手动开启 |
| 使用过程中权限被系统回收 | 下次扫描时检测权限状态，无权限时提示但不崩溃，已提取的快递仍可查看 |
| 授予权限后又关闭 | 已提取数据不受影响，新短信无法扫描，列表顶部 banner 提示"短信权限已关闭" |

## 二、短信数据

| 场景 | 处理 |
|------|------|
| 收件箱为空 | 空状态 IP 展示 + 文案："还没有快递消息，坐等包裹到来～" |
| 短信全是非快递内容（0 条匹配） | 空状态："暂未发现快递短信。可以试试添加匹配规则，或检查短信权限。"  |
| 短信含 emoji / 特殊字符 | 匹配时保留原文，emoji 不影响字符串 indexOf |
| 短信超长（>1000 字） | 正常处理，匹配引擎无长度限制 |
| 短信内容含换行符 \n | 匹配时换行符视为普通字符，前后缀可跨行；分词展示时换行符保留 |
| 跨语言短信（英文/中英混合） | 正常处理，前后缀锚点按原文字符匹配 |
| 彩信（MMS） | 仅处理文本部分，忽略图片附件 |
| 短信无发件方（ADDRESS 为 null） | SmsReader 兜底为空串。配了发件方过滤（senderPattern）的规则会排除这类短信（保守策略，空串不可能含发件方锚点）；未配发件方过滤的规则不受影响，正常匹配 |

## 三、规则相关

| 场景 | 处理 |
|------|------|
| 用户删光了所有规则（含预置） | 快递列表空状态："还没有匹配规则，添加规则后才能提取快递信息。" + 跳转按钮 |
| 规则名称为空 | 保存时校验，名称为空不允许保存，Toast 提示"请输入快递公司名" |
| 同名规则 | 允许存在（不同用户可能有不同地区的同公司短信格式），列表按创建时间排序 |
| 规则所有字段锚点全空 | 保存时警告："至少配置一个字段，否则规则无法匹配任何内容" |
| 前后缀在短信中出现多次 | 取第一次出现的位置，结果预览可检查是否正确 |
| 前缀和后缀之间有换行或空字符 | 截取时去除首尾空白 |
| 前缀在整个短信中找不到 | 该字段为 null，卡片不显示该字段（v1.1.0 起「不完整」标记已移除，isIncomplete 列已删） |
| 编辑已有规则 → 保存 → 是否需要重新扫描 | 提示："规则已更新，是否用新规则重新扫描未匹配的短信？" |

## 四、导入导出

| 场景 | 处理 |
|------|------|
| 导入文件不是合法 JSON | Toast："文件格式不正确，请选择 JSON 文件" |
| JSON 结构不符合规则格式 | Toast："规则格式不正确，缺少必要字段" |
| 导入的同名规则已存在 | 弹窗列出同名规则，逐条选择"覆盖 / 跳过" |
| 导入文件包含 100+ 条规则 | 正常导入，不做数量限制 |
| 导出时规则列表为空 | Toast："暂无规则可导出" |

## 五、快递数据

| 场景 | 处理 |
|------|------|
| 同一单号被两条不同规则匹配 | 取匹配字段多的；字段数相同取规则顺序靠前的 |
| 同一短信多条规则都能匹配 | 同上，只生成一条快递记录 |
| 新短信与已有记录单号相同但取件码不同 | 可能是新的取件通知（同一个包裹换柜），覆盖旧记录 |
| 新短信与已有记录完全相同 | 去重忽略 |
| 一键全部已取但列表为空 | 按钮置灰不可点击 |
| 按天已取但该天无未取快递 | 该天不显示按钮 |

## 六、稳定性

| 场景 | 处理 |
|------|------|
| App 扫描中途被杀进程 | 下次启动时重新扫描上一次未完成的批次 |
| 数据库升级（App 更新） | Room Migration 处理，旧数据保留 |
| 系统短信数据库被其他 App 修改 | 无影响，取件宝读取到的是当时的快照 |
| 设备存储空间不足 | Room 写入失败时 Toast 提示，不崩溃 |
| 设备无 SIM 卡 | 不影响，短信读取不依赖 SIM 卡 |

## 七、空状态总览

| 位置 | 空状态 |
|------|--------|
| 快递列表 — 无短信权限 | IP + "需要短信权限才能提取快递信息" + 授权按钮 |
| 快递列表 — 有权限但 0 匹配 | IP + "暂未发现快递短信" + 添加规则入口 |
| 快递列表 — 有权限有规则但没匹配到 | IP + "当前没有快递，有新快递时会自动出现～" |
| 匹配规则 — 无规则 | IP + "还没有匹配规则" + 新增按钮 |
| 匹配规则 — 自定义规则为空 | 预置规则区正常显示，自定义区显示"暂无自定义规则" |
